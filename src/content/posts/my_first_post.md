I have already started the course and set up a Virtual Machine in my OpenSuse Tumbleweed. It took a while to run the Ubuntu server iso installer in Virtualbox. I had to do a lot of research on Gemini. The problem actually was on kernel mismatch between my OS:

> Running OpenSUSE Kernel: 6.18.9-1-default

> Installed VirtualBox App: 7.2.14

So when I logged in with latest OpenSUSE kernel then the installer of Ubuntu Server ran smoothly. I think I did it 3-4 days ago, I was running short of time so I couldn't actually install the OS in the VM.
